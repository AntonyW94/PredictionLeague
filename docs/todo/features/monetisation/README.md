# Monetisation

Feature plans for generating revenue from the site, structured to stay clearly on the right side of UK gambling and payments law (we sell software/service access, not gambling, and never hold prize money).

## Features

| Feature | Description | Priority |
|---------|-------------|----------|
| [season-passes](season-passes/) | One-off paid Season Pass gating participation, with a free trial for new players and an optional SMS reminder tier | Medium |
| [season-challenges](season-challenges/) | Earnable badges tied to a season pass (stub — future follow-up) | Low |

## Out of Scope (pending legal advice)

- Routing paid-league **entry fees** between players via Stripe Connect — requires a UK gambling-law solicitor's sign-off before any build/go-live.
