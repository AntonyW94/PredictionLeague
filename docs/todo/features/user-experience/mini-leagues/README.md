# Mini-Leagues

## Status

**Not Started** | In Progress | Complete

> **Note (June 2026):** Don't confuse this with private leagues. The "mini leagues" the roadmap marks complete are private leagues joined by 6-character entry code (`League.EntryCode`, `JoinLeagueCommand`) - that is shipped. This plan's distinct concept - sub-leagues *within* an existing league (a subset of its members with their own leaderboard) - is genuinely not built.

## Summary

Sub-leagues within existing leagues allowing users to create smaller groups for more personalised competition among a subset of league members.

## Priority

**Low** (roadmap)

## Requirements

- [ ] Create mini-league
- [ ] Invite subset of members
- [ ] Separate leaderboard
- [ ] Mini-league management
